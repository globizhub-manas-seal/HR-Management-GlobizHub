PUBLIC

                        5 users for 3 months)
  /careers            — public job board (tenant-published jobs)
  /register/wizard    — 10-step org signup (business-email OTP required;
                        gmail/yahoo/outlook rejected by design). New orgs
                        start FREE: 5 users, 3 months — no trial, no card.
                        Upgrade anytime to the paid annual contract.

BILLING MODEL (super-admin controlled — nothing hardcoded)
  - Freemium: 5 users / 3 months, then the workspace locks to billing until
    they upgrade (HTTP 402 with an upgrade message).
  - Paid: annual contract invoiced upfront (users × ₹49 × 12). Seats added
    mid-term get a prorated annual invoice from their add date until
    contract end. Renewal invoice auto-issues 30 days before contract end;
    paying it extends the contract.

NOTE: Razorpay keys are not configured in the sandbox, so checkout runs the
" sandbox gateway " — it goes through the exact same server-side HMAC
verification path as real Razorpay callbacks. Add your real keys to
hrms-backend/.env (RAZORPAY_KEY_ID / KEY_SECRET / WEBHOOK_SECRET) and set
SANDBOX_PAYMENTS=false for production.

SEEDING (fresh deploys)
  cd hrms-backend && npm run seed          # super admin + plans + config + coupons
  npm run seed:demo                        # + the demo tenant above
  node scripts/manage-superadmin.js create <email> <password>   # more admins
